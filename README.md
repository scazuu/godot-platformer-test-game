## Godot Platformer Test Game
This repository is me trying out **Godot 4** for the first time, will be sticking to it as the **UI** and **Inspector** seems much nicer than the other engines I have tried out.</br>

The game was made by heavily following [Brackey's How to make a Video Game - Godot Tutorial](https://youtu.be/LOhfqjmasi0).</br>

I also tried wrapping my knowledge that i learned in Unity/C# into GDScript to make **Pause and Main Menus** which the tutorial doesnt cover. They have a in-built tween package!</br>
